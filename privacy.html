برنامهٔ دسکتاپ

MasQL پایگاه دادهٔ پروژه و پیشرفت آموزشی را روی رایانهٔ شما ذخیره می‌کند. به حساب کاربری نیاز ندارد و کد SQL یا پاسخ تمرین‌های شما را به این وب‌سایت ارسال نمی‌کند.

این وب‌سایت

این سایت ایستا، ابزار تحلیل بازدید، تبلیغات یا کوکی رهگیری اضافه‌شده ندارد. فونت‌ها و تصاویر از خود سایت بارگیری می‌شوند. میزبانی بر عهدهٔ GitHub Pages است و اطلاعات اتصال ممکن است طبق سیاست حریم خصوصی گیت‌هاب پردازش شود.

دریافت برنامه و پشتیبانی

فایل‌های نصب روی GitHub Releases میزبانی می‌شوند. دریافت فایل یا ثبت گزارش مشکل، تابع شرایط خدمات و حریم خصوصی گیت‌هاب است. پایگاه دادهٔ خصوصی، گذرواژه یا اطلاعات شخصی را در گزارش‌های عمومی قرار ندهید.
